# Browser Agent Relay

Chrome-расширение для управления одной выбранной вкладкой через личный
HTTPS-посредник и локальный MCP-сервер. Это репозиторий расширения:
сервер и MCP настраиваются отдельно. Без них управление из чата не работает.

## Установка

1. Откройте [Releases](https://github.com/heroboec/browser-agent/releases/latest).
2. Скачайте `browser-agent-extension.zip`, распакуйте в постоянную папку.
3. Откройте `chrome://extensions`, включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное расширение**, выберите папку `extension`.
5. Откройте нужный сайт и войдите обычным способом.
6. Откройте настройки расширения:
   - **Адрес посредника** — адрес вашего HTTPS Worker, без пути;
   - **Ключ устройства** — ваш `DEVICE_TOKEN`, не `ADMIN_TOKEN`;
   - **Разрешённый сайт** — точный origin, например `https://example.com`;
   - обновите список вкладок и выберите рабочую вкладку.
7. Оставьте **Подтверждать каждое изменение** включённым,
   отметьте **Разрешить управление**, сохраните и предоставьте доступ к двум адресам.

Адрес посредника и ключи не встроены в исходники. Их выдаёт владелец вашего
посредника. Не публикуйте ключи и данные профиля Chrome.

## Возможности

- Чтение текста, элементов и очищенного HTML текущей страницы.
- Ввод, выбор значений, клики и переходы внутри разрешённого origin.
- Подтверждение изменений и кнопка остановки.
- Локальный журнал до выполнения действия; неизвестные исходы автоматически не повторяются.

Поддерживается только верхний документ выбранной вкладки: iframe, Shadow DOM,
canvas, скриншоты и загрузка файлов не поддерживаются.

## Обновления

### Быстрый сеанс (0.1.1+)

В блоке **Состояние** включите **Быстрый сеанс**, чтобы расширение проверяло
задания примерно раз в секунду вместо 30 секунд. Сеанс длится 15 минут;
держите настройки открытыми и видимыми (Chrome замедляет фоновые вкладки).
Подтверждения остаются включёнными. При ошибках интервал растёт до 30 секунд.
Без заданий это около 3 600 запросов/час, плюс результаты и MCP: учитывайте
квоты Cloudflare. После закрытия настроек или окончания сеанса остаётся обычный
опрос раз в 30 секунд. Кнопка «Остановить» отключает управление целиком.
Обновление только расширения, без деплоя сервера.

В настройках есть блок **Версия и обновления**. Репозиторий по умолчанию:
`heroboec/browser-agent`. Проверка запускается только кнопкой
**Проверить обновления**, запрашивает доступ к API GitHub и не передаёт
ключи посредника или данные страницы.

При наличии новой версии откройте релиз, скачайте архив, замените файлы
в прежней папке и нажмите **Перезагрузить** на `chrome://extensions`.
Обновите рабочую страницу и проверьте выбранную вкладку.

## Безопасность

Посредник получает данные страницы. Эвристическая очистка не гарантирует удаления
всех секретов и персональных данных. Подключайте только разрешённые вам сайты.
Ключ устройства и текущий журнал хранятся в локальном профиле Chrome,
не зашифрованы от владельца компьютера. Не публикуйте профиль и журналы.

Расширение не выполняет произвольный JavaScript от ИИ и не читает cookies API.
События синтетические: некоторые сайты могут их не принимать.
Подтверждение клика не гарантирует, что сайт сохранил изменения:
после действия необходимо снова проверить страницу.
